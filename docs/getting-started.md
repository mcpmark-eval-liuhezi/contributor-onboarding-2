# Getting Started

A short first-day walkthrough for new contributors. You should be up and running in well under an hour.

## 1. Get oriented (10 minutes)

* Read [`docs/overview.md`](./overview.md) to understand what this repository is and how the documents are organized.
* Read [`docs/code-of-conduct.md`](./code-of-conduct.md) — it applies to all contributors from day one.

## 2. Set up your workspace (15 minutes)

1. Make sure you have a GitHub account and are signed in.
2. Fork or clone this repository locally:

   ```bash
   git clone https://github.com/mcpmark-eval-liuhezi/contributor-onboarding-2.git
   cd contributor-onboarding-2
   ```

3. Install a text editor of your choice (VS Code, Vim, etc.) — the docs are plain Markdown, so nothing heavier is required.

## 3. Introduce yourself (5 minutes)

* Join the project discussions and say hello. Don't be shy — everyone here started exactly where you are now.

## 4. Make your first change (20 minutes)

1. Create a branch for your change:

   ```bash
   git checkout -b docs/my-first-edit
   ```

2. Improve something small — fix a typo, clarify a sentence, or add a missing step.
3. Commit and push your branch, then open a pull request.
4. A maintainer will review it and help you polish it. Once it's merged, congratulations: you're a contributor!

## 5. Where to get help

* Open an issue in this repository for questions about the documentation.
* Ask questions in your first pull request — reviewers are happy to help.

Welcome aboard. We're glad you're here!
