# Overview

Welcome! This repository is a **documentation starter kit** for new contributors. Its purpose is to give everyone joining us a single, well-organized place to learn what the project is about, how we work together, and what their first day should look like.

## What this repository is

`contributor-onboarding-2` is the home of our onboarding documentation. It is intentionally documentation-first: there is no application code here, just the reference material that new contributors need before they touch any of our other repositories. Think of it as the front door to the project.

## How the documents are organized

All onboarding documents live in the [`docs/`](./docs) directory:

| Document | Purpose |
| --- | --- |
| [`docs/overview.md`](./docs/overview.md) | This file — an orientation to the repository and a map of the other documents. |
| [`docs/code-of-conduct.md`](./docs/code-of-conduct.md) | The standards of behavior we hold everyone to, and how to report problems. |
| [`docs/getting-started.md`](./docs/getting-started.md) | A short first-day walkthrough: what to read, what to install, and what to do first. |

The root [`README.md`](../README.md) is the entry point. It summarizes the project and links directly to each document in the kit.

## Suggested reading order

1. Start with this overview to get oriented.
2. Read the [Code of Conduct](./code-of-conduct.md) — it applies to everyone, always.
3. Follow the [Getting Started](./getting-started.md) walkthrough on your first day.

If you notice something missing or out of date, opening a pull request is the perfect first contribution. Welcome aboard!
