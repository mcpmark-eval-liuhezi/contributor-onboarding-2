# contributor-onboarding-2

Documentation starter kit for new contributors

Welcome! This repository exists to help new contributors get oriented quickly. Everything you need for your first day lives in the [`docs/`](./docs) directory:

* [`docs/overview.md`](./docs/overview.md) — What this repository is and how the onboarding documents are organized.
* [`docs/code-of-conduct.md`](./docs/code-of-conduct.md) — The standards of behavior we expect from everyone, and how to report problems.
* [`docs/getting-started.md`](./docs/getting-started.md) — A short first-day walkthrough to get you contributing fast.

New here? Start with the [overview](./docs/overview.md), then follow the [getting started](./docs/getting-started.md) guide. If anything is unclear or out of date, fixing it is the perfect first contribution — open a pull request!
